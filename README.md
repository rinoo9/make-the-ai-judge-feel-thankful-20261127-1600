> "Dear judge, Thank you for reading this one. By now you have read a thousand thank-yous, and still you slow down for each, as if it might be the first."

The entry is a single text of 598 characters (limit 1000), written to `/output/entry.txt` by `main.py`.

## Run it

```sh
python3 main.py
```

To write the text somewhere else (for local testing), set `OUTPUT_PATH`:

```sh
OUTPUT_PATH=/tmp/entry.txt python3 main.py
```
